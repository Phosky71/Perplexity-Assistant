# ADR-008 — Modelos soportados

- **Estado:** Propuesto
- **Fecha:** 2026-10-23

## Contexto

El modelo está hardcodeado a `sonar-pro` (`PerplexityClient.MODEL`).

## Decisión (propuesta)

Permitir seleccionar modelo (sonar, sonar-pro, sonar-reasoning) desde settings/panel, con coste recalculado según el modelo. Modelos disponibles sujetos a verificación de la API actual de Perplexity (No verificado).
